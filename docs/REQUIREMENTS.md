## 1. 产品目标

**品名（已定）**：中文 **花花世界**；外文品牌名 **Vivondo**（意英拼合自造词，取 vivid + mondo，表纸醉金迷、眼花缭乱的尘世，非花卉义）。

制作一款类似掷骰买地环游的桌游：棋盘为外圈环状格位，以**国家地产**为主，夹杂**特殊事件格**；玩家可购买 / 升级 / 特性化地产，对手踩到己方地产时通常需付地租。

交付见 [Q-009](#q-009)；技术栈见 [T-009](./TODO.md#t-009)。

## 2. 棋盘结构

### 2.1 拓扑（已定）

| 项 | 结论 |
|----|------|
| 形状 | 正方形外圈环（四边等长） |
| 每边中间格 | **10**（不含角格；含地产 + 事件） |
| 角格 | **4**（非普通地产） |
| 全环总格 | **44** = 40 中间格 + 4 角 |
| 行进方向 | 从起点角 **顺时针** |
| 中央区 | **中上 = HUD**；**中下 = 跑马场**（内圈深绿写「花花世界 / Vivondo」） |

### 2.2 中间格构成（已定）

| 类型 | 数量 | 分布 |
|------|------|------|
| 国家地产格 | 26 | 见 §3 |
| 普通事件格 | 8 | 白底橙问号；抽唯一事件池 |
| 赌城入口 | 2 | 意大利后、美国后；入口进中央跑马场 |
| 可买设施 | 2 | 石油、矿山 |
| 港口 | 2 | 大西洋航线；付 400 互传 |
| 角格 | 4 | 起点 / 机场 / 医院 / 赌场 |

### 2.3 边内插入

以 §2.5 序列为准。普通事件 8（单一牌池）+ 赌城入口 2 + 可买设施 2（石油、矿山）+ 港口 2；每边 E 最多 2；意大利与美国后均为「赌城入口 + E」。

### 2.4 区域环序（已定）

从起点顺时针：

**亚洲 → 欧洲 → 非洲 → 南美洲 → 中美洲 → 北美洲 → 大洋洲**

（北美与南美相对早期草案已对调。）

## 4. 地价 / 地租（已定框架 · T-002）

### 4.1 地价分档

1. **500+**：五常中的中美英法 + 日、澳、德、加 —— 地价均 **> 500**（俄罗斯单独见 400+）  
2. **400+**：新西兰、墨西哥、巴西、印度、沙特、意大利、**俄罗斯** —— 地价均 **≥ 400**  
3. **其余**：伊朗（亚仅剩）≥ 南美剩余 > 中美 > 非洲 > **斐济（最低 180）**

### 4.2 地租

地租 ≈ 地价 ÷ 8，取近似后 **末位为 0 或 5**。允许「地租相同、地价不同」。

### 4.4 可买设施（已定）

|------|------|------|------------------|

## 5. 地产格视觉（已定方向）

- 仅在格子 **底部涂色条**（非整格铺色，避免花眼）

- **角格、特殊事件格背景为白色**；事件格以橙色「E」标识

### Q-009 · 技术实现与交付形式

**已定**：
- **GM 由电脑托管**：银行 / 发薪 / 牌池 / 拍卖主持 / 收付结算均为程序自动执行，**不需要也不允许**玩家操作 GM。

- **音频**：引入简单 **无版权 / CC0 或明确可商用** 的 BGM 与音效（掷骰、买地、付租、事件、赌场等）；来源与署名写入项目说明。
