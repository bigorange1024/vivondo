### T-006 · 特殊事件与赌城入口支线 `已完成`

- 关联：[Q-006](./REQUIREMENTS.md#q-006) · [R-030](./RULES.md#r-030) · [R-031](./RULES.md#r-031) · [R-032](./RULES.md#r-032)
- **结论**：
  - 单一事件池 **24 张**：可持有 4 + 即时 20（R-030；含 E18 强制拍卖 / E19 换位 / E20 免租 token）
  - 事件格面为橙色大问号
  - 每玩家每种可持有卡最多 1；重复抽到则回库且 GM 补偿：出院卡 **100**、赌场VIP卡 **200**
  - 持卡专用抵消：**出院卡→仅医院**；**赌场VIP卡→跑马场 或 E18 强制拍卖**（也可不用）
  - 跑马场 **21 格**（含 1 起终点）；事件格 钱10/脚5/枪5，排列 `(钱脚钱枪)×5`；钱=`D×40`
  - 每回合 1d6 前进；**进场当回合必须掷骰离开起点**；**到达或越过起终点即离场**；回大地图任选赌城入口
  - 场内仍对外围债务负责；每边 E≤2；全图 E=8
- **可选后调**：事件卡数值微调与试玩平衡；跑马场格面绘制打磨（不挡关闭本项）

### T-013 · 拒绝购买时是否拍卖 `已完成`

- 关联：[Q-013](./REQUIREMENTS.md#q-013) · [R-015](./RULES.md#r-015) · [T-020](#t-020)
- **结论**：落到无主地（含油田/矿山/港口）选择 **不买** 时直接跳过，**不触发拍卖**。筹资/破产/E18 拍卖见 [R-017](./RULES.md#r-017)，与拒买无关。

<a id="t-014"></a>

### T-014 · 玩家交易 / 抵押 / 出售 `已完成`

- 关联：[Q-014](./REQUIREMENTS.md#q-014) · [R-016](./RULES.md#r-016) · [T-020](#t-020)
- **结论（MVP）**：
  - **不做** 玩家间交易、向 GM 抵押换现金
  - 国家地产变现：**仅** R-017 强制拆房 + GM 拍卖（及 E18）
  - 油田 / 矿山 / 港口：不可拍卖，可 **半价退回 GM**（破产则无条件收回）
- 二期若重开：再定交易物、抵押汇率、赎回等
