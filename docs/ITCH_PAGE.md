## English details

### What is it?
**Vivondo** is a browser board game: roll around a ring of countries, buy land, collect rent, build and specialize, and win by **region dominance** or by being the last player standing. UI and rules support Chinese and English.

This indie game was made by the author in remembrance of a paper board game from childhood.

### Features
- 2–4 players: humans and/or local AI
- Outer ring: properties, events, airport, ports, hospital, stock exchange
- Inner casino track: cash, racing, and slot mini-games
- Built-in rules manual and full event-card list

### How to run (itch web build)
Click **Run game** on the itch.io page — no Node.js install required.

### Important · Saves (please read)
- Saves live only on **this device + this browser** (localStorage). There are 9 slots; **manual save only** — no autosave.
- **Not cloud saves.** They do **not** sync across devices or browsers.
- Changing browsers/devices, clearing site data, or closing an incognito/private window can **wipe all saves**.
- Screenshot or note important progress yourself. Do not rely on itch or browser “sync” to keep progress.

### Notes
- **Single-player / hot-seat style:** opening the page on multiple devices starts separate games, not one shared online table.
- Third-party fonts are under SIL OFL; the game itself is proprietary — see in-game EULA and `EULA.md`.
- Some text or assets may be AI-assisted.

### Requirements
A recent desktop or mobile browser (Chrome / Edge / Firefox / Safari recommended). Landscape works best.
