## A. 回合与移动

<a id="r-001"></a>

### R-001 · 掷骰前进 【已定】

- 玩家在自己的回合使用 **1 枚六面骰（1d6）**，棋子沿棋盘环按点数 **顺时针** 前进（含事件格与角格）。  
- **不**存在「事件授权掷 2 骰来移动」；当前事件池亦无此类牌。  
- **两次骰子合计** 仅用于非移动结算：开局出发顺序（R-004）、证券参赌（R-044）、拍卖出价顺序（R-017）、跑马场格面判定（R-031）等。人类在需掷两次时须点两次按钮（每次一枚）；AI 由系统掷完。  
- 常态不采用「双骰相同再掷 / 三连进狱」作为基础规则。

关联：[Q-007](./REQUIREMENTS.md#q-007) / [T-007](./TODO.md#t-007)、[Q-012](./REQUIREMENTS.md#q-012) / [T-012](./TODO.md#t-012)。

### R-002 · 经过或停留起点 【已定框架】

<a id="r-003"></a>

### R-003 · 回合阶段顺序 【已定】

每位玩家的回合按以下阶段 **依次** 执行（不可跳步；某阶段无事可直接进入下一阶段）：

| 阶段 | 名称 | 内容 |
|------|------|------|
| 1 | 回合开始 | 轮到当前玩家；结算「回合开始时」类持续效果（若有） |
| 2 | 掷骰 | 默认掷 **1d6**（见 R-001）；赌场等另有 2d6 规则时按其条款 |
| 3 | 移动 | 按点数顺时针前进；途经起点等按 R-002 / 角格规则即时结算 |
| 4 | 格子结算 | 依**最终落点**结算：无主地产购买选项 / 对手地付租 / 己方地 / 事件 / 角格等 |
| 5 | 经营窗口 | 可进行规则允许的 **升级 / 特性化** 等（具体何时可对哪些地操作 → R-011 / R-022 / T-004）；MVP **不含**玩家交易 / 抵押（R-016） |
| 6 | 回合结束 | 检查胜利条件（R-018）；若未结束则交给出发顺序中的下一位玩家（R-004） |

说明：
- 阶段 4 结算过程中若导致破产，按 R-017 处理，并立即再检 R-018。
- 阶段 5 不得再移动棋子（除非事件明确给予额外移动，那视为插入的特殊流程，完成后回到阶段顺序约定）。

关联：[Q-011](./REQUIREMENTS.md#q-011) / [T-011](./TODO.md#t-011)。

<a id="r-004"></a>

### R-004 · 先手与行动顺序 【已定】

1. **出发顺序裁定**：开局进入 **定顺序** 阶段。每位玩家各掷 **2 次骰子**（取总点数；人类玩家须点两次、每次一枚；AI 自动掷完）。**总点数更大** 者更先出发；按点数从高到低排出完整行动顺序。
2. **平手加赛（两两比较）**：若当前玩家的点数与**此前某位已投玩家**相同，则仅这两人再各掷 2 次骰子加赛，直到分出高低；加赛只决定这两人之间的先后，**不改变**他们相对其他玩家的档位（加赛结果不改变非加赛玩家的出发顺序）。人类参与加赛时同样须自行点两次掷骰。  
   - 例：A=7，B=8，C=8，D=10 → 档位为 D ＞（B 与 C）＞ A；B、C 加赛。若加赛 B=12、C=11 → 出发顺序 **D → B → C → A**；若加赛 B=3、C=12 → **D → C → B → A**。
3. **行动顺序**：定序结束后整局按该出发顺序循环行动（下一位 = 顺序中的下一名未出局玩家）。
4. 随机数来源由实现保证公平（各端可见结果）；与移动用的 1d6 无关。

关联：[Q-016](./REQUIREMENTS.md#q-016) / [T-016](./TODO.md#t-016)。

### R-016 · 交易 / 抵押 / 出售 【已定】

### R-017 · 现金不足、拆房、拍卖与破产 【已定】

以下称 **GM** = 银行 / 中立托管方。  
**实现约定**：GM **始终由程序自动托管**（发薪、收费、洗牌、拍卖主持、代币发放/收回等），**没有**人类玩家扮演 GM 的席位或操作界面。

#### A. 触发与强制还债

玩家须支付地租、罚金、机票、赌场追加等而 **现金不足** 时：

1. **不得拒绝还债、直接认输出局。**  
2. **有房可拆则必须拆房**；拆至己方已无房可拆后，**有地可拍卖则必须拍卖**（可连续拍卖多处），直到债务付清，或已无地可卖且仍无力付清。  
3. **最低资产**：现金应保持至少 **5**。若现金 **低于 5**（含 0 或负数）且仍有可拍卖国家地产，必须强制拍卖筹资至至少 5；若已无国家地产可拍卖且现金 ≤ 0 → 破产出局。不得自行宣布放弃。  
4. **唯有在无钱还清当前到期债务时**（且已按上序完成强制拆房/拍卖变现）方可 **破产出局**。

#### B. 强制顺序：先拆房，后拍卖

1. **拆房（优先）**  
   - 仅 **未特性化** 且房屋数 ≥ 1 的地产可拆。  
   - 每拆 **1 级房屋**：房屋数 −1，**GM 返还 ⌊该格地价 ÷ 2⌋**。  
   - 只要仍有可拆房屋，就必须先拆，不得跳过直接卖地或认输。  
   - **由债务人自行选择**拆哪一处（可连续拆多处，直到现金够付或已无房可拆）；AI 自动择屋。  
2. **卖设施 / 港口**  
   - 无房可拆后：债务人选择将油田 / 矿山 / 港口 **半价退回 GM**（仍不足再进入拍卖）。  
3. **卖地**  
   - 国家地产：**只能拍卖**，不能直接卖给 GM。  
   - **已特性化** 地产视为无房屋：无房可拆，只能拍卖。  
   - 拍卖标的由债务人选择。

#### C. 拍卖（GM 主持）

**原地主不参与竞拍**；其余未出局玩家可参与。

1. **出价顺序**：参与者各掷 **2d6**，大者先；平局仅组内重掷，重掷不跨组比较（例：A=10，B=C=7 → BC 重掷后顺序可为 A→B→C）。  
2. **起拍价** = 地价 × 2（无人出到起拍价 → 流拍）。  
3. **一口价** = 地价 × 10（喊出或竞价达到则立即成交）。  
4. 每次加价至少 **+50**。  
5. **成交**：成交额 **GM 一半、原地主一半**。  
6. **流拍**：GM 收回为无主地；GM 向原地主退 **地价 − 50**。  
7. **重置**：成交转手或 GM 收回后，该地变为 **普通 0 屋地产**（无特殊类型效果）。

#### D. 清偿与破产（无 GM 补贴差额）

1. 变现所得必须优先用于偿还 **当前这笔到期债务**。  
2. **债主只从债务人处拿钱**：能收回多少是多少；**差额 GM 不予补贴。**  
   - 例：A 欠 B **100**，A 无地产且现金只剩 **20** → A 破产出局，B 只得到 **20**，其余 **80** GM 不补。  
3. 破产条件：在已执行强制拆房与可拍卖地产的拍卖/流拍之后，仍无法用现金 **足额** 偿还到期债务 → 债务人将 **剩余现金全部** 交给债主（若债主为 GM 则交 GM / 清零），然后 **出局**。  
4. **出局清仓**：  
   - **仅国家地产**进入破产拍卖；流拍则 GM **无条件**收回为无主（不向出局者退款）。  
   - **油田 / 矿山 / 港口**：不进入拍卖，由 GM **无条件**收回为无主（不清偿半价退款）。  
   - **飞机 / 轮船 / 免租 token**：由 GM **无条件**收回。  
   - **出院卡 / 赌场VIP卡**：由 GM 收回后 **立刻回归事件抽牌堆并洗牌**（同 R-030 回归洗牌约定）。  
5. 破产清仓的国家地产 **须先完成破产拍卖队列**（可竞拍者出价；流拍归 GM），**全部清算完毕后** 再检胜利条件 R-018-2（不得因「已只剩一人」而跳过拍卖、直接收归）。

说明：本条拍卖用于还债变现、破产清仓，亦用于事件 **E18 强制拍卖**（流程同 C；标的一律按 **普通 0 屋** 计）。**不买无主地不拍卖**（R-015）。

<a id="r-018"></a>

### R-018 · 胜利条件 【已定】

对局在满足以下 **任一** 条件时立即结束，该玩家获胜：

1. **区域称霸**：该玩家率先 **完整拥有 4 个地产区**（七区：亚 / 欧 / 非 / 南美 / 中美 / 北美 / 大洋洲）的全部国家地产；且这 4 个区中 **至少有 1 个是 5 国区**。  
   - 当前 5 国区仅为：**亚洲、欧洲**。  
   - 「完整拥有」= 该区每一个国家地产格均归属该玩家。
2. **独占存活**：其余玩家均已 **破产**，仅剩该玩家未破产。  
   - **单机含 AI**：若全部 **人类玩家** 均已破产，对局 **立即结束**（不再继续纯 AI 对战）；在仍存活的玩家中按现金最高者获胜（平手取名单靠前）。

关联：[Q-008](./REQUIREMENTS.md#q-008) / [T-008](./TODO.md#t-008)；破产定义见 [R-017](./RULES.md#r-017)。

## B. 地产归属与付费

<a id="r-010"></a>

### R-010 · 同区买齐涨租 【已定】

同一地产区（亚 / 欧 / 非 / 南美 / 中美 / 北美 / 大洋洲）的国家地产若被 **同一玩家全部拥有**，则：

- **未特性化** 的该区地产：应收地租 **×2**（在房屋公式之后翻倍）。  
  - 即：先算 `基础地租 × (1 + 房屋数)`，再 ×2。  
- **已特性化** 的该区地产（工业 / 商业 / 旅游）：**不受** 本条翻倍影响，只按 R-023 结算。

例：买齐亚洲 5 国，中国为工业国，其余 4 国 0 屋 → 踩中国付 `基础×5`（不翻倍）；踩其余亚洲国付 `基础×1×2`。

<a id="r-011"></a>

### R-011 · 无主地产购买 【已定】

棋子落在 **无主** 国家地产格时，玩家可选择：

1. **购买**：支付该格购买价，地产归自己，房屋数 = 0；或  
2. **不买**：无事（MVP 不拍卖）。

不能对无主地直接加盖或特性化。

<a id="r-012"></a>

### R-012 · 对手地产付租与结算优先级 【已定】

棋子**最终落点**为 **其他玩家拥有的国家地产** 时，按下表 **从高到低** 依次判定；某步已结束付租流程则后续步骤不再执行。

| 步 | 名称 | 规则 |
|----|------|------|
| 1 | **是否进入付租** | 下列任一成立则 **不付租**，本流程结束：落点为自己的地 / 无主地；落点为油田、矿山或港口（即使他人持有也不向地主另付地租，R-027 / R-028）；**地主正在住院**（R-042）；本格结算被改写或跳过（如 E19 换位后不结算、位移声明不经本格等）。 |
| 2 | **应收地租** | 仅按地主侧公式计算，见 [R-013](#r-013)（含成套×2、特性化、旅游掷骰）。 |
| 3 | **油田** | 付款方若持有油田：未特性化格按 [R-027](#r-027) **自动**减免；已特性化格（应收 > 0）须 **选择**是否发动油田（发动则付基础租并交还油田，否则付全额）。得到 **实付额**（可为 0）。无油田则实付额 = 应收地租。 |
| 4 | **免租 token** | 在 **已公布实付额之后、实际付款之前**，付款方可选择将免租 token 交还 GM（R-029）：本次 **实付视为 0**，本流程结束。不使用则继续。实付已为 0 时通常无需使用。 |
| 5 | **付款** | 将实付额付给该地所属玩家；现金不足按 [R-017](#r-017) 筹资。 |

**免租 token 适用范围**：仅取消本流程中的 **玩家间国家地产地租**。不可用于付给 GM 的费用、港口船费、机票、赌场、事件罚金、跑马场等。

关联：[Q-010](./REQUIREMENTS.md#q-010) / [T-010](./TODO.md#t-010)。

<a id="r-013"></a>

### R-013 · 地租计算（应收） 【已定】

本条只计算 R-012 第 2 步的 **应收地租**（尚未套油田、尚未用免租 token）。

1. **未特性化**：`基础地租 × (1 + 房屋数)`（房屋 0～3）。  
2. 若该区已买齐且本格未特性化：将上式结果再 **×2**（R-010）。  
3. **已特性化**：只按 R-023（工业×5 / 商业公式 / 旅游×(持有数上限3 + 1d6)），**不再** 因 R-010 翻倍。旅游国的 1d6 在本步掷定。  

油田减免与免租 token **不属于**本条，见 R-012 第 3～4 步与 R-027 / R-029。

<a id="r-014"></a>

### R-014 · 踩到自己的地产 · 加盖与特性化 【已定流程】

仅当最终落点为 **自己拥有** 且 **尚未特性化** 的地产时，可选择支付进行一次「加盖」或跳过：

| 当前房屋 | 本次加盖 | 费用 | 结果 |
|----------|----------|------|------|
| 0～2 | 第 1～3 次加盖 | **1× 该格地价**（持矿山则再 −50，见 R-027） | 房屋数 +1 |
| 3 | 第 4 次加盖 | **2× 该格地价**（持矿山则再 −50，见 R-027） | 清空全部房屋，**必须**转为三种特殊地产之一（工业国 / 商业国 / 旅游国） |

说明：

- 无主购买不计入「加盖次数」；加盖仅发生在拥有之后再次踩到该格。  
- 每次踩到最多加盖 **1** 次；可不付费，保持现状。  
- 未满 3 屋时不能特性化；满 3 屋后的下一次加盖即特性化。  
- 特性化后该格不再加盖房屋（特殊地产后续是否再升级 → 默认否，MVP）。  
- 经营窗口（R-003 阶段5）是否允许对非落点地加盖 → **默认否**（仅落点可加盖），与「走到自己的地产」表述一致。

<a id="r-022"></a>

### R-022 · 房屋与特性化费用 【已定框架】

见 R-014。第 1～3 次加盖各付 1×地价；第 4 次（特性化）付 2×地价。  
持有**矿山**设施时，每次加盖费用再 **−50**（见 R-027）。

### R-020 · 地价与基础地租 【已定】

**地价分档：**

1. **500+**：中国、美国、英国、法国、日本、澳大利亚、德国、加拿大 —— 地价均 **> 500**  
2. **400+**：新西兰、墨西哥、巴西、印度、沙特、意大利、俄罗斯 —— 地价均 **≥ 400**  
3. **其余排序**：伊朗 ≥ 南美（阿根廷、智利）> 中美 > 非洲 > 斐济（**180**，全局最低）

### R-023 · 三种特殊地产 【已定】

特性化时必须三选一：**工业国 / 商业国 / 旅游国**。特性化后不再盖房、不可改类型（MVP）。

| 类型 | 对手踩到时地租 | 备注 |
|------|----------------|------|
| **工业国** | **基础 × 5** | 稳定高租；无起点额外补贴 |
| **商业国** | **基础 × (3 × 完整拥有的大洲数)** | 完整大洲数为 0 时地租为 **0** |
| **旅游国** | **基础 × (持有旅游国数（上限 3）+ 1d6)** | 持有数按地主当前旅游国总数计；1 处时 ×2～×7，3 处时 ×4～×9 |

转卖或被 GM 收回后：恢复普通地产（见 R-017-C5），本表效果消失。  
同区买齐涨租（R-010）**不**再作用于上表结果。

<a id="r-027"></a>

### R-027 · 可买设施：油田与矿山 【已定】

环上两处设施格（非国家地产、不可加盖）：

| 设施 | 位置 | 价格 |
|------|------|------|
| **油田** | 伊朗后一格 | **1000** |
| **矿山** | 智利后一格 | **1000** |

#### 购买与处置

1. 无主时踩到：可选 **买 / 不买**（与国家地产相同；MVP 拒买不拍卖）。  
2. **不可拍卖**。自愿/还债变现时：只能以 **半价 500** 退回 GM，恢复为无主。  
3. **破产出局清仓**（R-017）：油田/矿山由 GM **无条件收回**为无主（不给付半价）。  
4. 踩到**他人已购**的油田/矿山：本格 **不另收租**（价值在持有效果）。  
5. 不计入大洲成套、不参与「完整拥有大洲」计数；不可特性化、不可盖房。

#### 油田 · 持有效果（付地租时）

持有油田地契的玩家，向他人支付国家地产地租时：

1. **未特性化**地产：  
   `实付 = max(0, 应收地租 − 10 × (1 + 该格房屋数))`  
   （即按房屋等级少付一截：0 屋 −10，1 屋 −20，…，3 屋 −40；在成套 ×2 之后再减。对应 R-012 第 3 步。）**自动生效**，不失去油田。  

2. **已特性化**地产（工业国 / 商业国 / 旅游国）：付款方**二选一**（应收已为 0 时无需选择，实付 0）：  
   - **发动油田**：实付该格卡面 **基础地租**（不采用工业×5 / 商业×(3×大洲) / 旅游抬升）；随即把油田地契 **无偿交还 GM**，油田恢复为无主。  
   - **不发动**：按 R-023 应收全额支付，**保留**油田。  
   - 若踩中的是 **商业国** 且应收为 **0**：实付 **0**，不触发本选择、不失去油田。

#### 矿山 · 持有效果（加盖时）

持有矿山地契的玩家，每次对自己国家地产**加盖**（含第 4 次特性化）时，该次费用 **−50**（减后不低于 0）。

<a id="r-028"></a>

### R-028 · 大西洋港口（可买 + 付费传送） 【已定】

环上两处 **港口**格（英国后一格、墨西哥后一格），同属一条大西洋航线。地价 **1000**（与油田/矿山相同）。

#### 购买与处置

1. **可购买**，地价 **1000**（刻意偏贵，压缩前期现金流，与机场类似的取舍）。无主时：因掷骰**停留**或因**出航/E14 传送到达**，均可选择 **买 / 不买**（拒买不拍卖）。  
2. **不可用于拍卖**（还债/破产/E18 均不可选港口；同油田/矿山）。自愿变现或还债筹资：可 **半价 500** 退回 GM。  
3. **走到自己的港口**（含掷骰停留与传送到达）：可选择是否半价卖回 GM，或保留。  
4. **破产出局**：港口由 GM **无条件收回**为无主，**不进入拍卖**、不给付半价。  
5. **不可加盖 / 不可特性化**；不计入大洲成套。  
6. **其他玩家**路过、停留或使用该港口时：**不向地主付租**。

#### 自有港口收益（地主）

仅当 **地主本人** 路过或停留 **自己拥有的** 港口时，由 GM 发给固定收益（不要求必须出航）：

| 该玩家持有港口数 | 每次路过或停留一处自有港口 |
|------------------|---------------------------|
| 1 | **+20** |
| 2 | **+50** |

- 掷骰前进/后退路径上每经过一处自有港口结算一次（含最终落点）。  
- **出航**（付费/免票/E14）：到达另一港口时，若到达港为自有，再发一次收益。持有 2 处时，典型「停 A 再出航到 B」= 停 A 领 50 + 到 B 领 50。  
- 船票仍按下列规则付给 GM，与港口收益独立。

#### 出航

踩到任一港口时（买/保留/他人港之后）可选：

1. **停留 / 不出航**：无事；或  
2. **出航**：移到 **另一处港口**（不经银行起点、不触发领薪）：  
   - **未**使用轮船 token：船费 **200**；完成后若无轮船 token 则领取 1 枚。  
   - **使用**轮船 token：**免票**，收回 token。  
   - 可捂着 token 仍付 200。  
3. **防来回刷**：出航完成后先结算到达港（买/半价退回等），**不得再次出航**，然后本回合结束。  
4. 付不起船费则不能出航。

与机场区别：港口两端互传、船费固定；机场任意国家地产、机票按地价。

### R-029 · 代币（飞机 / 轮船 / 免租） 【已定】

实体/UI 代币均由 **GM 发出与收回**；下列每种每名玩家 **最多持有 1 枚**。

| 代币 | 图标 | 如何获得 | 持有效果 / 使用 |
|------|------|----------|-----------------|
| **飞机 token** | 飞机 | **起飞完成时**领取（机场付费起飞且未使用飞机 token，或 E13 等免费起飞）；**已持有则不再领取，亦无其他补贴** | 下次在机场付费起飞时，可选用：机票改为 **终点地价 × 1**，然后 GM **收回**该 token。也可继续捂在手里，仍按 ×2 付机票（不额外再领 token）。**不影响**银行（起点）领薪，过起点 **不** 因本 token 被收回 |
| **轮船 token** | 轮船 | **出航完成时**领取（港口付费出航且未使用轮船 token，或 E14 等免费出航）；**已持有则不再领取，亦无其他补贴**（含不再发 100） | 下次在港口付费出航时，可选用：**免票**，然后 GM **收回**该 token。也可捂在手里，仍付 200（不额外再领 token）。捂着 **无** 其他收益 |
| **免租 token** | 房屋 | 事件 E20「一次免租」从 GM 领取；**已持有则不再领取**（无其他补偿） | 按 [R-012](#r-012) 第 4 步：在公布实付额之后、付款之前，可交还 GM，使 **本次玩家间国家地产地租** 实付为 0。**不可**用于：付给 GM 的费用、港口船费、机票、赌场、事件罚金、跑马场等 |

飞机 token **不能**主动丢弃；仅在机场选用抵扣机票时交回 GM。  
轮船 token **不能**主动丢弃；仅在港口选用免票出航时交回 GM。  
免租 token 仅在选择使用时交回；不强制使用。

### R-030 · 普通事件格与事件牌池 【已定】

落到事件格（白底 **橙色大问号 ?**）时，从 **唯一事件牌池** 顶抽 1 张并结算。

**洗牌**：每当有人完成一次抽卡（抽出该张之后），对 **剩余抽牌堆** 立刻重新洗牌。可持有卡因重复持有而立刻回归牌池时，回归后也须对抽牌堆再洗一次。弃置堆仅在抽牌堆抽尽时整堆洗回成为新的抽牌堆（洗回后即为当前抽牌堆）。  
**读档**：恢复盘面时保留抽牌堆/弃牌堆的**卡牌集合**，但对抽牌堆**重新洗牌**（不保证读档后下一张与存档时相同）；掷骰本身每次独立随机，读档不固化后续点数。

**存档存储（玩家须知 · 中英）**：网页/itch 版仅存于当前设备当前浏览器（localStorage），非云、不跨设备；清站点数据可能丢失。开发模式优先写 `save/slot-N.json`。  
**Save storage (player notice)**: Web/itch builds store saves only in this device + this browser (localStorage) — not cloud, not synced. Clearing site data may wipe them. Dev mode prefers `save/slot-N.json`.

| E18 | 强制拍卖 | 你必须选择自己拥有的 **1 处国家地产** 交付拍卖（**不可选**油田、矿山）。无论该地当前房屋数多少、是否已特性化，均 **视为普通无加盖（0 屋）地产** 进入拍卖，适用 [R-017](#r-017) **C. 拍卖**（原地主不参与竞拍；起拍/一口价按卡面地价；成交/流拍后重置为普通 0 屋）。若你 **没有** 可拍卖的国家地产：本事件无效。若你持有 **赌场VIP卡**：可按 R-032 **弃置该卡取消本次强制拍卖**（不拍卖） |
| E19 | 位置互换 | 可选：指定 **1 名未出局且不在跑马场内** 的其他玩家，与其 **互换大地图位置**。换位后 **双方都不** 触发新落点的事件、结算或效果（含买地、付租、角格、领薪等）。也可选择 **不换**。**不能**与身在跑马场内的玩家互换 |
| E20 | 一次免租 | 从 GM 领取 **1 枚免租 token**（房屋图标；已持有则不再领取，无其他补偿）。用法见 R-029 |

说明：标「与 GM」的收支只对 GM；现金不足时按 R-017 筹资。位移「不经银行起点」不触发途经领薪。**逆时针经过或停在银行（起点）不领薪**（R-041）。仅顺时针途经/停留才领薪。

#### 抽到可持有牌

1. 若该玩家 **尚未** 持有同名卡：收入手牌（每名玩家出院卡最多 1、赌场VIP卡最多 1）。  
2. 若已持有同名卡：该张 **立刻回归牌池**，GM 补偿：出院卡 **100**、赌场VIP卡 **200**；仍只保留原先 1 张。  
3. 弃置/用后的可持有牌进弃牌堆；牌池抽尽后弃牌洗回成为新抽牌堆。即时事件结算后进弃牌堆（不立刻洗回）。**每次抽卡后剩余抽牌堆必须洗牌**（见上）。

<a id="r-032"></a>

### R-032 · 可持有卡：出院卡与赌场VIP卡 【已定】

#### 持有上限

每名玩家同时最多：**出院卡 ×1**、**赌场VIP卡 ×1**（见 R-030）。

#### 专用抵消（也可继续捂住）

| 持有卡 | 可抵消 | 不可抵消 |
|--------|--------|----------|
| **出院卡** | 即将 **进入医院住院**（R-042） | 进跑马场；E18 强制拍卖 |
| **赌场VIP卡** | 即将 **进入跑马场**（R-031）；抽到 **E18 强制拍卖** | 进医院 |

触发对应效果时，可选择：

1. **弃置该专用卡** → **取消本次**对应效果（进医院 / 进跑马场 / E18 强制拍卖），本回合按「未触发该效果」继续；或  
2. **不使用**，继续持有，并正常承受该效果。

**赌场VIP卡 · 强制拍卖**：叙事上表示 VIP 身份尊贵、不必接受强制拍卖；机制上仅当你 **自己抽到 E18** 时可弃卡取消，**不能**阻止因 R-017 还债而产生的拍卖。

#### 其他

- 赌场VIP卡 **不** 等同于可买设施地契；不提供油田/矿山类被动，也不占国家地产。  
- 卡面与数字版 UI 须能显示「手中持有的出院卡 / 赌场VIP卡」。

<a id="r-031"></a>

### R-031 · 赌城入口与中央跑马场 【已定框架】

对局关系：跑马场内为 **玩家 ↔ GM** 结算（金钱进出 GM；加盖/拆房改的是玩家自己的大地图地产）。

#### 布局

- 赌城入口格 **2 处**：**蒙特卡洛赌城**（顶边意大利后，扑克牌图标）、**拉斯维加斯赌城**（底边美国后，筹码图标；后接 E）。  
- 中央跑道水平平放、左右对称，约占全图约 1/7。  
- **全场共 21 格**：**1 格为起点/终点**（同一格），其余 **20 格** 为事件格。

**事件格（20）数量与排列：** 钞票 **10**、赛马（马头） **5**、老虎机 **5**。  
自起点格之后环向重复：`(钞票 → 赛马 → 钞票 → 老虎机) × 5`。  
起点/终点格 **不挂** 三图标效果；格面为 **F1 黑白方格旗**样式（与环上黑白单色格区分，避免 21 格奇偶撞色）。

#### 进入

1. 踩中赌城入口 → 默认强制进入跑马场（不经大地图起点）；棋子置于跑马场 **起点/终点格**。  
2. **进场当回合必须立刻掷 1d6 并前进**，**不得停留在起点格结束回合**；人类先看到棋子停在起终点再点「掷骰」离开；AI 进场后自动掷骰前进。按移动结果结算（若点数使棋子到达/越过起点则视为跑完一圈并离场——极罕见）。  
3. 起点格本身无三图标效果；进场放置不单独触发离场。  
4. 若持有赌场VIP卡：可按 R-032 弃卡取消进入。出院卡不能抵消。  
5. 赌场VIP卡仅由事件池 2 张专卡获得（R-030）。

#### 场内移动

1. 跑马场内自己的回合：掷 **1d6**，沿跑道前进该点数。  
2. 若本次移动（含赛马额外移动）使棋子 **到达或越过起点/终点格** → **立即离场**，不再结算起终点上的图标（本无图标）。  
3. 若未离场且停在事件格 → 结算该格图标。

#### 共用判定：两次掷骰差值

踩中钞票/赛马/老虎机时：掷 **2 次骰子**，`D = 第1次 − 第2次`（−5～+5）。人类玩家须点两次、每次一枚；AI 自动掷完。

#### 格效果（踩中即结算）

**1. 钞票图标（钱）**

- 掷得 `D` 后：`金额 = D × 40`。  
- `金额 > 0`：GM 付给玩家该金额。  
- `金额 < 0`：玩家付给 GM `|金额|`（不足则按 R-017 筹资）。  
- `金额 = 0`：无事。  
- （`D` 为 −5～+5 时，单次约 −200～+200。）

**2. 赛马图标（马头 · 前进 / 后退）**

- 掷得 `D` 后：沿跑马场再移动 **`D` 步**（`D > 0` 前进，`D < 0` 后退，`D = 0` 不移动）。  
- 移动结束后：若已到达/越过起终点则离场；否则 **立即结算新落点**（赛马可连锁）。

**3. 老虎机图标（地产加盖 / 拆房）**

- 掷得 `D` 后：  
  - **`D > 0`（免费加盖一层）**  
    - 玩家在自己拥有的 **国家地产** 中选 1 块，**免费**房屋数 +1。  
    - **不可选**：已是特殊地产（工业/商业/旅游）；或当前已有 **3 屋**（再加盖会触发特性化——跑马场老虎机 **禁止** 用此途径特性化）。  
    - 若没有可选地产（无地、或全是特殊地产/全是 3 屋）：本效果跳过。  
    - 不支付地价；矿山减免不适用（本已免费）。  
  - **`D < 0`（拆除一层）**  
    - 玩家在自己拥有的国家地产中选 1 块拆除一层：  
      - **普通地产**（未特性化）：房屋数 ≥ 1 则可房屋数 −1；若选中的地当前 0 屋则须另选，若全部普通地都是 0 屋且也无特殊地可拆 → 不拆除。  
      - **特殊地产**：允许选中；拆除后变为 **普通地产且房屋数 = 3**（取消工业/商业/旅游类型）。  
    - **有可选目标时必须拆除，不可跳过**；若玩家没有任何可拆国家地产：不拆除。  
    - 拆房 **不** 经 GM 退款（与 R-017 筹资拆房不同；此处为跑马场事件）。  
  - **`D = 0`**：无事。

#### 与外围联动

身在跑马场期间，外围向你收租/追债时 **照常付钱**；R-017 拆房/拍卖/破产全程适用。

#### 离场与回到大地图

1. **离场条件**：走完一圈——任意一次移动使棋子 **到达或超过** 跑马场起点/终点格（进场时的首次放置除外）。  
2. 离场后：玩家 **任选一处赌城入口格** 回到外围并按该格结算。  
3. 场内期间外围收租/债务仍适用（R-017）。  

（1d6、约 21 格一圈时，期望大约 **6 回合**；赛马格会改变实际回合数。）

<a id="r-041"></a>

### R-041 · 银行（起点）（C0） 【已定】

格面名称：**银行（起点）** / **Bank (GO)**。

1. 基本工资 **W = 500**（R-019）。**无**按领地数量等动态加成。  
2. **仅顺时针**移动才会触发本格领薪：  
   - **途经**（顺时针经过）：本应领 **1×W**；  
   - **停留**（顺时针移动的最终落点为本格）：本应领 **2×W**。  
3. **逆时针**经过或因后退等落在本格：**一律不领薪**（不触发途经/停留工资）。这样可避免「后退越过起点却领薪」的漏洞。  
4. **飞机 token 不影响本格**：顺时针途经/停留时 **照常发薪**；GM **不**因经过本格收回飞机 token（飞机 token 仅在机场选用抵扣机票时交回，见 R-029 / R-043）。  
5. 入院传送、港口互传、机场起飞等 **不经过** 本格的位移，不触发领薪。

<a id="r-042"></a>

### R-042 · 医院（C2） 【已定框架】

1. **路过**不停靠：无事。  
2. **停在医院**或被事件送入：进入住院——**必须**跳过接下来 **2 次**自己的「掷骰 + 移动」（强制，不可自愿提前结束），除非特殊事件另有规定，或按 **R-032** 弃置 **出院卡** 取消本次入院（赌场VIP卡 **不能** 抵消入院）。  
3. **住院收钱禁令**：自入院起至再次可以掷骰移动之前（`hospitalSkips > 0`），该玩家 **不能收取任何款项**（地租、银行工资、事件奖金、赌场奖金、港口收益等）。他人踩到其国家地产时 **免付本次地租**（不触发免租 token）。**唯一例外**：因 **被迫拍卖**（E18 / 还债筹资）成交或流拍退款而得的拍卖款。  
4. 住院期间默认仍可进入阶段 5 经营窗口（细节随经营规则）。  
5. 暂无提前出院费；已在住院中默认 **不可** 再弃出院卡提前结束住院（仅抵消触发瞬间），除非日后事件另述。

<a id="r-043"></a>

### R-043 · 机场（C3） 【已定】

落到机场时 **可选择**（不强制起飞）：

1. **不飞 / 停留**：无事；或  
2. **起飞**：选 **任意一个国家地产格** 为终点：  
   - **机票**（付给 GM；付不起则不能以该方式飞）：  
     - **未**使用飞机 token：机票 = **该格购买价 × 2**；起飞完成后若尚未持有飞机 token，按 R-029 **领取 1 枚**（每名玩家最多 1 枚）。  
     - **使用**飞机 token：机票 = **该格购买价 × 1**（原价）；起飞完成后 GM **收回**该飞机 token。  
   - 持有飞机 token 时可选择本次 **不用**（仍按 ×2 付机票，token 继续持有，且不因本次起飞再领第二枚）。  
   - 立刻移到该格，**不经银行（起点）**；落地后立刻结算该格。

<a id="r-044"></a>

### R-044 · 证券交易所（C1） 【已定】

落到证券交易所时：**必须参赌**（支付入场费并结算），**不可选择不赌**；除非特殊事件另有规定（如免赌、改写本格效果等）。

1. 支付入场费 **C = 200** 注入奖池，掷 **2 次骰子**（人类点两次、每次一枚；AI 自动掷完）。  
2. 结算：

| 结果 | 条件 | 效果 |
|------|------|------|
| 大失败 | 双 1 | 入场费沉没；再向奖池追加 **200**（不足则追加剩余现金并做破产检定） |
| 大成功 | 双 6 | 取走当前奖池 **全部** |
| 退还 | 非上述，且两点之和 **= 7** | 取回本次入场费 **200** |
| 赢 | 非上述，且两点之和 **≥ 8** | 从奖池取 **400**（不足则取光） |
| 输 | 其余（和 ≤ 6 且非双 1） | 入场费沉没 |

3. 奖池开局为 0；来源为入场费与大失败追加。  
4. 若现金不足支付入场费 200：按 R-017 **强制拆房 → 设施半价退回 → 拍卖地产** 筹资；仍不足才破产。大失败追加 200 同样走 R-017，不得跳过筹资直接出局。

### R-050 · 格位规模 【已定】

<a id="r-051"></a>

### R-051 · 事件格、赌城入口、设施与港口分布 【已定】
